# Окружение сборки (харнес)

> Проект собирался некоторое время назад, поэтому версии ниже указаны ориентировочно — по актуальным на тот момент стабильным релизам инструментов. Ничего специфичного/нестандартного при сборке не использовалось.

## Среда разработки

- **IDE:** Arduino IDE (2.x)
- **Плата:** ESP32 Dev Module

## Пакет плат

- **ESP32 by Espressif Systems** — версия из Boards Manager, ориентировочно 2.0.x

## Библиотеки (Library Manager)

| Библиотека            | Назначение                          | Версия (ориентировочно) |
| ---------------------- | ------------------------------------ | :----------------------: |
| OneWire                | Работа с шиной 1-Wire (DS18B20)      | 2.3.x                    |
| DallasTemperature       | Опрос датчиков температуры DS18B20   | 3.9.x                    |
| Adafruit SSD1306 / U8g2 | Работа с дисплеем SSD1306/SSD1315    | последняя стабильная      |
| Adafruit GFX Library    | Графический движок для дисплея       | последняя стабильная      |
| EEPROM (встроенная)     | Сохранение параметров                | входит в ESP32 core       |

## Примечание

Специфичных инструментов сборки, кастомных харнесов или тестовых окружений в проекте не использовалось — стандартная сборка и заливка прошивки через Arduino IDE.
