## Общее описание

Скрипт предназначен для автоматического управления системой отопления с регулировкой температуры теплоносителя на основе погодозависимой кривой и температуры в помещении. Управление осуществляется тремя ТЭНами с возможностью адаптивного включения/отключения.

## Структура репозитория

## Аппаратная часть

### Компоненты

- **Микроконтроллер:** ESP32
- **Дисплей:** SSD1306 / SSD1315 (128x64, I2C)
- **Датчики температуры:** 3 шт. DS18B20 (улица, помещение, подача теплоносителя)
- **ТЭНы:** 3 канала управления (пины 12, 13, 15)
- **Зуммер:** 1 пьезоизлучатель (пин 16)
- **Кнопки:** 4 шт. (Menu, Exit, Up, Down) с подтяжкой к питанию

### Подключение пинов

| --------------------------------------------------------------------------------------------- | :-------: |
| Кнопка Menu                                                                                    |    25     |
| Кнопка Exit                                                                                    |    26     |
| Кнопка Up                                                                                      |    27     |
| Кнопка Down                                                                                    |    14     |
| ТЭН 1                                                                                          |    12     |
| ТЭН 2                                                                                          |    13     |

## Алгоритм работы

### Основные функции

1. **Чтение датчиков**
   - Неблокирующий режим конвертации DS18B20
   - Разрешение 11 бит (время конвертации ~375 мс)
   - Экспоненциальный фильтр (α = 0.3) для сглаживания показаний

2. **Погодозависимая кривая**
   - 6 опорных точек для расчёта оптимальной температуры теплоносителя
   - Интерполяция между точками
   - Масштабирование кривой (коэффициент 0.6–1.6)
   - Коррекция по температуре помещения

3. **Управление температурой теплоносителя**
   - Автоматический расчёт целевой температуры
   - Адаптивное повышение при недогреве
   - Снижение при перегреве (удержание от 5 мин до 2 часов)

4. **Управление ТЭНами**
   - Поочерёдное включение/отключение
   - Периодическая проверка эффективности
   - Защита от частых переключений

### Особенности алгоритма

#### Room Hold режим

При достижении целевой температуры в помещении автоматически снижается температура подачи теплоносителя для предотвращения перегрева.

#### Адаптивное повышение

При медленном прогреве система анализирует скорость нагрева и при необходимости повышает целевую температуру теплоносителя.

#### Аварийная защита

- Контроль обрыва датчиков
- Защита от перегрева теплоносителя
- Звуковая сигнализация
- Автоматическое отключение ТЭНов при аварии

## Параметры настройки

### Основные

- Целевая температура помещения (5–35 °C)
- Максимальная температура подачи (30–100 °C)
- Минимальная температура подачи (15–50 °C)

### Сервисные

| Параметр           | Диапазон | Описание                                            |
| ------------------- | -------- | ---------------------------------------------------- |
| Масштаб кривой       | 0.6–1.6  | Коэффициент масштабирования погодозависимой кривой   |
| Сдвиг по комнате      | 0–4.0    | Влияние отклонения комнатной температуры от 22 °C    |
| Δ старт нагрева       | 2–10 °C  | Разница для включения нагрева теплоносителя           |
| Δ откл. охлаждения    | 1–10 °C  | Разница для отключения ТЭНов при перегреве             |
| Интервал теста        | 10–120 с | Период проверки эффективности ТЭНов                    |
| Δ теста ТЭНа          | 0.3–3 °C | Минимальный прирост температуры за интервал теста      |

## Управление с клавиатуры

### Обычный режим

- **Menu** — вход в меню
- **Любая кнопка** — отключение звука аварии

### Меню

- **Up/Down** — навигация по пунктам
- **Menu** — вход в редактирование параметра
- **Exit** — сохранение параметра
- **Exit** (без редактирования) — выход из меню

### Сервисное меню

Доступ через пункт «СЕРВИС ->» в главном меню.

## Отображение на дисплее

### Обычный режим

- Температура улицы / дома / цель помещения
- Температура подачи / цель подачи
- Статус ТЭНов (1/2/3)
- Режим работы: `[АВАР]`, `[ХОЛД]`, `[НАГРЕВ]`, `[ОХЛАЖД]`, `[Ожидание]`

### Меню

- Основные параметры с возможностью редактирования
- Сервисные параметры
- Индикация сохранения

## Защита и безопасность

1. **Контроль датчиков**
   - Обрыв датчика → авария
   - Зависание показаний (> 30 секунд) → авария
   - Несколько неудачных чтений подряд → авария

2. **Температурная защита**
   - Превышение `maxCoolantTemp + 5°C` → авария
   - Автоматическое отключение всех ТЭНов

3. **Таймаут меню**
   - Автоматический выход через 60 секунд бездействия

## Сохранение настроек

Все параметры сохраняются в EEPROM:

- Целевые температуры
- Параметры кривой
- Пороги управления
- Восстановление при перезагрузке

## Технические особенности

- Неблокирующий опрос датчиков
- Антидребезг кнопок (50 мс)
- Обновление дисплея каждые 150 мс
- I2C на скорости до 400 кГц
- Поддержка кириллицы на дисплее
- Случайный порядок включения ТЭНов для равномерного износа
